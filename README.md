# 👥 Customer Segmentation Analysis

## 📌 Overview
This project applies **KMeans clustering** (from `scikit-learn`) to segment customers based on purchasing behavior and attributes. The goal is to identify distinct customer groups for better marketing and business decisions.

## 🛠️ Tools & Libraries
- Python  
- NumPy – numerical operations  
- Pandas – data handling  
- Matplotlib & Seaborn – visualizations  
- Scikit-learn – KMeans clustering
